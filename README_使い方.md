## コート上の手書きメモ・落書き

「ペン」を選び、指・スタイラス・マウスでコートに直接描けます。文字を手書きしたり、選手を丸で囲んだり、動きを自由な線で描けます。ペンで描いている間は選手やボールを動かしません。選手の番号を読みやすくするため、落書きはマーカーの後ろに描画します。

- 色は8色と自由な色、太さは「細い／標準／太い」の3段階です。描いた線ごとに色と太さを保存します。
- 「落書き消し」で線をタップ・なぞると、その線全体が消えます。線の一部だけを削る方式ではありません。選手・ボール・矢印は消しません。
- 「落書きを全消去」は手書きの線だけを消します。「戻る／やり直す」で1本の線や消去操作を取り消し・再実行できます。
- 2本指では拡大・移動します。途中まで描いてから2本指にした場合も、その描きかけの線を取り消して画面操作に切り替えます。
- 書き終えたら「プレーを保存」を押してください。落書きはプレー保存・複製・端末下書き・JSON・PNGに含まれます。PNGは画像ですが、プレーとJSONの落書きは編集可能な線です。
- 全／半コート、スマホの縦向き、PC・TVの横向きでも相対座標を維持します。切り替えだけで線を消しません。
- TVの全画面表示にも「移動／ペン／落書き消し／戻る／やり直す」があります。色と太さの設定欄を表示する場合も、残りの領域にコートを収めます。
- テンプレート適用時は、矢印や落書きがあれば確認します。適用で消した落書きは「戻る」で復元できます。「初期配置に戻す」も配置・矢印・落書きを初期化しますが、取り消せます。

データ量を抑えるため、1プレー200本・合計8,000点、1本1,000点までにしています。長い線の上限になったら指を離して続きを描いてください。全体の上限になった場合は線を減らすか別プレーを使います。上限を超える落書き付きJSONは、現在の盤面やタイトルを変更せずに読み込みを拒否します。

**チーム内の端末も更新後にページを開き直してください。** 古いコードは落書きを扱わないため、古い画面から同じプレーを保存すると落書きが失われる場合があります。

## テレビ用の全画面表示

盤面の右上にある「全画面 / TV」を押します。プレー名・盤面・終了ボタンを表示し、入力欄やプレー一覧は隠します。全コートも半コートも、縦横比を保って画面内に収めます。番号や矢印も大画面向けの大きさに調整します。

対応する環境ではブラウザのFullscreen APIを呼び出します。APIが利用できない、または要求が拒否された場合は、ページ内を画面いっぱいに使う「TV / 画面内表示」になります。この場合、ブラウザのアドレスバーなどは残ることがあります。参考： https://fullscreen.spec.whatwg.org/

- テレビへの接続・ミラーリングは、端末の画面共有、AirPlay、HDMIなどで別途行ってください。このボタン自体にはテレビへ送信する機能はありません。
- TV表示は横方向のピッチです。スマホをミラーリングする場合は、端末も横向きにすると大きく表示できます。
- TV表示に入ると「移動」ツールになります。選手やボールのドラッグ、2本指での拡大・移動ができます。上の「ペン」で手書きへ切り替えられます。「全体表示」で拡大を解除します。
- 「全画面を終了」またはEscキーで編集画面に戻ります。ブラウザ側から全画面を解除した場合もTV表示を閉じます。
- 切り替えだけでは配置や未保存の編集は変わりません。TV表示中に選手を動かしたり落書きした場合は、終了後に「プレーを保存」を押してください。入る前に選んでいたツールと「盤面を拡大」の状態は、終了時に戻ります。
- TV表示だけで画面の拡大率・表示位置は100%に戻します。保存座標は変更しません。

## 保存まわりの修正

| 項目 | 新しい動作 |
| --- | --- |
| クラウドからの更新 | 別プレーの更新では編集中の内容を読み直しません。同じプレーが他端末で変わった場合は、未保存の編集を保って通知します。 |
| プレー切り替え | 未保存なら「保存して切り替える／保存せず切り替える／キャンセル」を選べます。保存に失敗したら元のプレーに留まります。ログアウトにも同じ確認があります。 |
| 複製 | 今の画面のタイトル・説明・名簿・配置・矢印・落書き・コートの種類を含めて複製します。元の保存済みプレーは変更しません。 |
| 保存の連打 | 保存中は1つの処理だけを実行し、ボタン・編集操作を一時的に止めます。初回保存での重複作成を防ぎます。 |
| 新規作成と失敗 | 「新しいプレー」はまず下書きとして開きます。クラウドには「プレーを保存」を押したときに作成します。保存失敗時は配置と説明を保ちます。 |

保存と削除では、読み込んだデータと現在のクラウドデータをトランザクションで照合します。競合時は上書きせず、「最新版を読み込む」か「別プレーとして保存」で進められます。通信が切れている場合はクラウド保存を成功扱いにせず、編集と端末下書きを保持します。

## 追加した編集機能

### 矢印の個別削除

「矢印削除」を選び、消したい矢印をタップします。保存済みの矢印も1本ずつ消せます。「戻る」で復元し、「やり直す」で再実行できます。矢印の近くを選びやすいように判定範囲を広げています。

### 保存状態と端末下書き

「新しい下書き／未保存／保存中／保存済み／保存できませんでした」を表示します。変更は約0.4秒後にそのブラウザのストレージにも下書き保存し、ページを閉じる・別アプリへ移る際も保存を試みます。

再度開くと下書きの復元ボタンを表示します。下書きはログインユーザー・チーム・プレーごとに分けます。端末下書きはそのブラウザ内だけの保存で、他端末への同期はクラウド保存が必要です。シークレットモードの終了やブラウザのデータ削除では下書きがなくなる場合があります。保存できない設定の場合は画面に通知します。

### PNG画像への書き出し

「画像（PNG）を書き出す」を押すと、タイトルと盤面、説明の先頭部分を1枚の画像にします。拡大表示中でも、切れていない盤面全体を書き出します。表示チーム・ポジションのフィルターは反映します。説明は画像内で最大8行、全文はJSONに残せます。

PNGを保存した後、LINEなどで通常の画像として共有できます。外部への自動送信は行いません。

### 配置テンプレート

「バランス配置／スクラム／ラインアウト／キックオフ」を選び「配置する」を押します。15人制・12人制に対応し、登録済みの選手名は保ちます。

テンプレートは配置を始めるための概略図です。チームで使う形に合わせて調整してください。配置変更時に矢印や落書きがあれば確認し、「戻る」で変更を取り消せます。

### 2本指で拡大・移動

盤面で2本指を広げる・縮めると100〜400%に拡大・縮小できます。2本指で位置も移動できます。画面の＋／−でも拡大でき、「全体表示」で戻れます。

選手を指でつかんだ後に2本目の指を置いた場合、最初のドラッグを取り消して画面操作へ切り替えます。拡大中も選手は1本指で動かせます。空いているところを1本指でドラッグすると盤面を移動できます。ページのスクロールは盤面の外で行います。

拡大率と表示位置は作業用の表示設定で、選手の保存座標を変えません。

## JSONの読み書き

JSONには盤面だけでなく、タイトル・説明・種別・相手名も含めます。従来の盤面だけのJSONも読み込めます。

読み込みは「別プレーの下書き」として行い、現在選択中のプレーへ勝手に上書きしません。読み込んだ後に保存してください。

## 前のバージョンから引き継ぐ機能

- スマホは縦方向、PCは横方向のピッチ表示。
- 全コート／半コートの切り替え。半コートでも両チームを配置できます。切り替え時は相対配置を維持する方式で、同じ実距離を維持したズーム表示ではありません。
- 相手は黒いマーカー・白い1〜15番。12人制は元の方針に合わせ1〜5番と9〜15番です。
- 味方FWは赤、BKは青。控え16〜23番（12人制は16〜21番）は白地に濃い番号。
- 矢印の8色と自由な色、色のプレー保存。
- ボールの立体感、パネル、グリップと縫い目。
- スクロールや画面復帰、描画コンテキスト復元時の再描画。
- 既存のFirestoreのチーム／プレーと、従来の0〜1の座標を使用。古い保存データにコート指定がなければ全コートとして読み込みます。

## オフラインプレビュー

`preview.html` は1ファイルで動くプレビューです。通常のブラウザで開いて操作できます。クラウドとは接続せず、このブラウザにだけ保存します。手書き・消しゴム・保存・複製・下書き・矢印削除・テンプレート・PNG・拡大操作は、本番と同じ編集コードを使用します。

iPhoneで試す場合は `preview.html` もリポジトリに置いて公開すると、サイトのURLの末尾に `preview.html` を付けて開けます。

## Firebaseへの変更点

SDKとFirebase設定は従来のものを使用します。保存データに `revision`、`clientRequestId`（新規作成時）、`lastEditorUid` を追加します。フィールド名を限定するFirestoreルールを使っている場合は、この追加が許可されるか確認してください。

落書きは `boardState.strokes` に `{points:[{x,y}],color,width}` の配列として追加します。`boardState.penColor` と `boardState.penWidth` も保存対象です。古いデータにこれらがなくても読み込めます。盤面内のフィールドを限定するルールがある場合は、これらも許可してください。Firebaseの設定やルールをこのZIPで自動変更することはありません。データ型・容量の参考： https://firebase.google.com/docs/firestore/manage-data/data-types 、 https://firebase.google.com/docs/firestore/quotas

トランザクション内で、読み込んだ版と最新の内容を確認してから更新します。以前のコードから更新されて `revision` が変わらない場合も、保存対象の内容を比較します。参考： https://firebase.google.com/docs/firestore/manage-data/transactions
